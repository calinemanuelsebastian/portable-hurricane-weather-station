# Limitations

- The prototype has not yet been calibrated against certified meteorological instruments.
- The wind-speed algorithm requires further refinement.
- Long-term outdoor operation has not yet been evaluated.
- The enclosure provides prototype-level protection, but harsh-weather deployment requires improved sealing and connectors.
- The current communication link uses nRF24L01 modules; longer-range versions may use LoRa transceivers.
